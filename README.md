# carnet-crypto
Carnet de trades crypto 100 % local, en français. Suivez vos positions Long et Short : ouverture, renforts, clôtures partielles et totales. Prix moyen pondéré, P&amp;L réalisé et latent nets de frais, winrate, profit factor, simulateur de renfort, notes et émotions. Aucune donnée envoyée, hors ligne, thème clair/sombre. Open source AGPL-3.0.
